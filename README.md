# gomonk.dev

## Telling subscribers about new content

Subscribers live in Substack (gomonk.substack.com → Subscribers), not here.
Substack only emails them when something is published there, so after adding
a post or a few collectables to gomonk.dev:

1. Push to `main` and wait for the site to deploy.
2. Write a short Substack post: title, two or three sentences, link to the
   new page (or a digest linking to several).
3. Publish it and send to everyone.

The welcome email in Substack's settings must contain the download links
promised on the subscribe page.
